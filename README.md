# Code from "The Digital Epidemiology of Social Media Behaviour and Mental Wellbeing in the Avon Longitudinal Study of Parents and Children (ALSPAC)"

This respository contains key Python and R Studio code I used throughout my thesis.

## Chapters 2-7

These contain the key R Studio code used in Chapters 2 to 7 of my thesis. This includes how variables have been generated or formatted, and how models were fitted. 

## Circular Statistics Generation

This contains the Python code used to generate the circular mean hour of Tweet posting variables, using long-form Twitter data. 

## Emotion Dyanmics Generation 

This contains the Python code used to generate the time-adjusted Mean Squared Successive Difference variables, used in Chapter 6 of my thesis.
